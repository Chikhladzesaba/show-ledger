# Show Ledger

Show Ledger helps creators see what each episode really earns, across every revenue stream.

It answers three questions:
1. What did each episode earn in total, minus what it cost to make?
2. Which revenue stream is growing, and which is shrinking?
3. How much of my income depends on a single source?

All numbers are entered by hand and stay in your own browser. Nothing is sent to a server.
